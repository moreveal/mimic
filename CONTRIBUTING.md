# Contributing to Mimic

Mimic welcomes focused bug reports and contributions that improve observable
Chrome compatibility, correctness, diagnostics, or measured runtime behavior.

Before opening a pull request, read [AGENTS.md](AGENTS.md), add focused regression
coverage where practical, and run the relevant checks documented in
[docs/getting-started.md](docs/getting-started.md#verification).

Every external code or documentation contribution requires acceptance of the
[Mimic Contributor License Agreement](CLA.md). The pull request CLA check records
acceptance through the contributor's authenticated GitHub account and must pass
before merge.

By accepting the CLA, contributors retain copyright in their contributions while
granting `moreveal` the rights stated in that agreement, including the right to
license contributions as part of Mimic under separate commercial or proprietary
terms.
