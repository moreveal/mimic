# Product Vision

**Mimic fills the gap between raw HTTP clients and full browsers.**

HTTP clients are fast and inexpensive, but automating complex websites with
them often requires reverse-engineering private APIs, authentication flows,
signatures, tokens, and client-side state.

Full browsers execute that logic for you, but also carry the cost of a rendering
engine designed to produce pixels that automation often never needs.

**Mimic executes the website's own JavaScript and browser logic without running
a traditional rendering pipeline—aiming for browser-level automation with
runtime costs closer to direct HTTP.**
