# Specified CSS values and saved rule serialization

The actual 045102 child stylesheet contains 204 initial rules. Replaying that original source through fresh independent headful Chrome 152.0.7977.82 instances and Mimic exposed 97 differing rules after the earlier whitespace patch. The generating causes were typed number/zero serialization, color forms, shadow components, origin keywords, slash/comma spacing, selector combinators, and duplicate declarations retaining their first position. The earlier limited synthetic keyframe oracle did not cover these causes.

The shared CSS declaration parser now serializes the measured property families from their types. Transform arguments distinguish number, angle and length, preserve unresolved var/env token streams, fold simple same-type calc sums, and reject the measured incompatible dimensions. Shadows serialize color and lengths consistently and reject negative blur/percentage lengths. Duplicate CSS source declarations move to their effective final position; mutation through setProperty retains its existing path. CSSRule selector serialization formats parsed combinators rather than replacing characters in selector strings.

All 204 original rule strings now match Chrome exactly in the private diagnostic .build/residual-dom-delegated/actual-rules-controls. No original selectors, rule arrays, payload hashes or colors were added to runtime code. Public regression coverage instead uses css_specified_values_oracle.js with independent synthetic inputs, including neighboring invalid dimensions, shadows, percentages and specified-versus-computed opacity. Its frozen reference retains launch/source metadata and the independent control. Existing frozen CSS/WebKit tests remain unchanged. Two older nonfrozen cascade checks now expect 0.8/0.4 instead of the raw author spellings .8/.4, supported by this frozen control.

A Goja Number.toPrecision defect for a negative large exponent surfaced while preserving existing huge-scale geometry: (-1e35).toPrecision(6) gives an invalid string in that adapter. The CSS formatter formats magnitude and then applies sign, retaining compatible CSS output without changing the global Number implementation. Raw scalar-goja-controls documents the independent underlying adapter issue.

This increment does not claim a complete CSS math/type grammar: nested advanced math functions and unmeasured layered/background syntax remain outside its focused implementation. The saved stylesheet contains none of those unresolved expressions. Original runtime replay remains the final payload-level validation.
