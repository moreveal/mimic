## Исправленные общие причины

1. **Selector reentry.** Внутренние document collections, tag/class/name collections, form elements, select options, radio grouping и title отдельного document вызывали публичные querySelector/querySelectorAll. Теперь используют закрытый selector engine. Oracle переопределяет публичные методы и проверяет одновременно результат и отсутствие неожиданных вызовов.
2. **Nonce internal slot.** Запись HTMLElement.nonce ошибочно создавала/меняла content attribute. Добавлен canonical Node nonce slot, согласованный с обычной attribute mutation, clone state и CSP checks. Namespaced nonce не меняет slot. Clone сохраняет slot для script/style/div. Дополнительные аспекты nonce concealment под CSP этим набором oracles полностью не покрываются.
3. **HTML fragment serialization.** Round-trip writer экранировал кавычки как `&#34;` и смешивал text/attribute/raw-text правила. Добавлен отдельный fragment serializer: `&quot;` в attributes, литеральные кавычки в text, корректный raw script/style и NBSP. Никаких замен по готовому payload.
4. **Coordinates.** Прежний rect model терял signed left/top и не проецировал проверенные CSS transforms. Добавлены position offsets, отдельные untransformed offset observations и affine corner projection. Проверены absolute/fixed, отрицательные offsets, translate, scale, display:none. Сложный flow, таблицы, intrinsic controls и extreme transforms остаются ограничением модели.
5. **Font shorthand.** `font: italic 150px serif` сохранялся строкой, а shaping читал отсутствующие longhands и использовал 16px. Обычные font shorthands раскрываются до cascade и shaping, включая reset-компоненты. Сложные ещё не разрешаемые формы сохраняются с diagnostic boundary, а не подменяются произвольным font profile.
6. **Native source между realms.** Export/import callable reference терял native binding name. Через private bridge передаётся только явно зарегистрированное native-name metadata, без чтения author getter/name/toString. Console namespace также участвует в native binding finalization. Отдельно исправлено представление Function.prototype.toString.
7. **Форма platform operations.** JS function declarations давали browser methods лишний own prototype и [[Construct]]. Finalizer делает такие operations неконструируемыми, сохраняет arity и aliases, нормализует автоматически полученные placeholder names. WebIDL constructors остаются constructors.
8. **SVG lifecycle во вложенном browsing context.** SVG text в скрытом/удалённом iframe продолжал иметь длину. Проверка layout eligibility теперь учитывает canonical frame lifetime и display embedding ancestors, включая Shadow DOM. Сначала replay выявил недостающий положительный shadow-frame случай; исправление дополнено oracle, не обнулением всех child rects.

Минимальные `.82` oracles и regressions: `internal/browser/testdata/execution_{cleanup,reentry,font,source,svg_lifecycle,operations}_{oracle.js,chrome152.json}`; runner `internal/browser/execution_cleanup_test.go`. Все проходят в обычном и snapshot V8 realm. Сохранены и промежуточные неудачные проверки; oracle expectations не ослаблялись ради прохождения.

## Четыре hash-поля: конкретные входы

Hash implementation не исправлялась: SHA-256 соответствует переданным bytes. Приватные diagnostic wrappers фиксировали digest input; хеш каждого input независимо проверен и сопоставлен с обычным replay. Расширенные hooks наблюдали временные iframe через contentDocument, поэтому были видны **точные SVG operations**, пропущенные первоначальным hook только главного realm.

| Поле | Генерирующая операция | Chrome input | Mimic before | Mimic after |
|---|---|---:|---:|---:|
| RKUE0 | sum(abs(x,y,width,height)) от SVG group getBBox | 4992.546875 | 567.3156223297119 | 4993.14998626709 |
| JRzmw6 | сумма компонентов getExtentOfChar(emoji string → index 0) | 88.95946502685547 | 88.96875 | 88.96875 |
| kRQwh3 | getComputedTextLength после скрытия iframe | 0 | 21.96875 | 0 |
| oSIr8 | сумма distinct getComputedTextLength / 100000 | 0.638944033908844 | 0.06857265625 | 0.638985625 |

Входной DOM: временный iframe, SVG group, четыре emoji/ZWJ строки и 15 текстовых строк, x/y=32, CSS scale(1.001), для длинных строк italic 150px serif. Точные inputs/DOM/CSS находятся в `.build/cleanup-012501/chrome-frame/` и `chrome-realms3/operations.json`; в production они не встроены.

Три оставшихся hash mismatch связаны с SVG text shaping/quantization и font environment. Извлечённый markup сериализует CSS scale с округлением; его повторный парсинг не сохраняет все исходные floating-point значения. Поэтому SVG markup-only oracle подтверждает общий font дефект, но не выдаётся за побитовый reproduction исходного hash. Нужны отдельные минимальные oracles для эффективного font scale, hinting и transformed glyph bounds; константы и подгонка hashes не использованы.
