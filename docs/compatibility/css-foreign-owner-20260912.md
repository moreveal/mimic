# Foreign-realm CSS and geometry projection

Borrowed getComputedStyle and geometry methods must observe the element owner document and its canonical style state. Previously a foreign getter tried to reconstruct geometry in its caller realm: viewport lengths used the caller viewport, and closed-shadow descendants appeared disconnected because the synthetic parent map belongs to the owner realm.

The existing computed-style owner callback now dispatches resolved values, document eligibility, layout boxes and transformed rectangles. Results are plain observations; CSSStyleDeclaration retains the invoking getter realm. Frozen controls show DOMRect and DOMRectList instead belong to the node wrapper creation realm, including after adoption. Private ElementGeometry realm bindings construct those objects in that realm while their numeric observations follow the current owner document. The original owner remains authoritative for stylesheet matching, shadow connectivity, inherited values and viewport state. Local ownership is cached only within an existing bounded style read; no additional persistent DOM copy or realm field is introduced. Public getComputedStyle and geometry methods are never invoked by the bridge.

Adoption exposed a scheduler defect: entering the foreign owner directly while the caller isolate remained occupied could deadlock. The callback now follows the existing synchronous cross-frame protocol: capture primitive arguments before switching owners, suspend through ReentrantRuntime.RunNested, run on the target owner, and restore the entry document. No page-global runtime lock is added.

The independent frozen Chrome152 oracle covers closed-shadow borrowed getters, viewport-relative widths, live font and iframe-size changes, disconnect/reconnect, author method replacement, direct getters after adoption into another document, and observations after that browsing context is removed. It checks computed declaration length and liveness, getClientRects, an offset accessor and object prototype identity as well as values and bounding rectangles. Both fresh headful controls and Mimic match. Raw launch/diagnostic evidence is .build/residual-dom-delegated/foreign-css-owner-final-controls; the retained synthetic oracle and full receipt are css_foreign_owner_oracle.js and css_foreign_owner_chrome152.json.

This package repairs owner routing for the supported box model. It does not introduce fragmented inline layout or a new rendering backend, and does not claim to extend the separate synthetic-shadow adoption model.

Validation: the focused CSS/computed-style/box-geometry, input, detached-frame and restored-bootstrap tests pass (80.898s). The new oracle also runs directly in Goja/V8 and in a restored snapshot realm; its entry-document depth returns to zero. Fresh A/B profiles use unique directories and exact Chrome152 metadata.
