Known measurement error: previous DOM.getOuterHTML snapshots used original source and are unsuitable as post-hydration DOM evidence. The actual runtime DOM and Mimic.captureSnapshot read canonical state; CDP was fixed and verified by regression tests. A skeleton count of 0 is insufficient: a React error fallback also removes skeletons.

Each new checkpoint requires a pinned source revision/hash; live endpoint→PID→executable verification; binary SHA; execution mode (compiled code / injected source / mocked host); registered/expected test counts; harness completion status; separate PASS/FAIL/TIMEOUT/NOTRUN and registration blockers. Preserve the previous denominator when changing the test scope. Validate the final page by its populated UI and absence of error fallback, not API presence or disappearance of a skeleton CSS class.
