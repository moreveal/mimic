# WebGL textures and compressed observations (2026-09-12)

Texture bindings now reference context-owned texture resources with independent
texture units, persistent parameters and copied image levels. Typed uploads,
subuploads, block uploads and aligned block replacements update that state.
Arithmetic shaders can sample 2D images with matching nearest or linear filters
and wrap modes. Draws retain their sampled image, so a later upload cannot change
an earlier queued observation. Context restoration invalidates old textures and
clears bindings through the same resource generation used by other WebGL objects.

S3TC, sRGB S3TC, RGTC and BPTC extensions are registered with their constants,
compressed format queries, upload validation and actual decoded observations.
The portable MIT-licensed `github.com/woozymasta/bcn` v0.7.0 decoder supplies BC1–3,
BC6H and BC7. Decoding uses one worker and no graphics device. Signed RGTC is
expanded directly into normalized floats to avoid lossy signed-to-byte conversion;
BC6H keeps HDR floats. The frozen device's BC1 three-color midpoint rounding is
applied before sRGB conversion. This dependency requires x/sys v0.47.0.

`WEBGL_debug_shaders` exposes the serialized immutable IR that the software shader
executor actually consumes. This is a real backend program, not a fabricated ANGLE
HLSL string. Fresh, sourced, compiled, retained-source and deleted shader states,
wrong resource types and error codes match the frozen Chrome controls. Translation
text necessarily describes the selected backend.

Seven independent frozen Chrome 152.0.7977.82 A/B fixtures cover resource/binding
identity and deletion, upload/subupload state, changed samples, all sixteen
compressed formats, source copying, aligned partial block replacement, malformed
lengths, dimensions and mip constraints, plus debug-shader lifecycle. Ordinary and
restored bootstrap tests pass. Private harnesses/results remain in the main
checkout `.build/residual-continuations-delegated/webgl-texture*`,
`webgl-compressed*` and `webgl-debug-shaders`.

A broader full-quad nonuniform-block probe remains in `webgl-compressed-varied`.
It exposes ten remaining S3TC/RGTC channel differences of 1–3 byte levels against
the native ANGLE device. These are codec interpolation/normalization precision
observations; their raw reference values have not been changed or hidden behind a
tolerance. BC6H/BC7 samples in that probe agree. This package does not claim exact
native-device compressed color precision for arbitrary blocks.

The bounded model does not yet execute cube/3D/array sampling, texture-backed
framebuffer draws, TexImageSource uploads, generated mip filtering, pixel-unpack
buffers or distinct minification/magnification filters. Those paths retain explicit
unsupported diagnostics rather than produce an invented successful draw. None of
these operations is generated by the saved payload's extension-inventory probes.
The remaining wider extension inventory (instancing, vertex arrays, multi-draw and
other raster features) remains separate work; adding names alone is insufficient.
