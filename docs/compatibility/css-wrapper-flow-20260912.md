# Wrapper geometry: conditional rules and normal flow

The exact saved 045102 API generator is ha(o.wrapper): getBoundingClientRect().top + "|" + .right, forwarded as wp and read into lgWCE7 by the child VM. An isolated instrumented replay of the original saved API records the wrapper, ancestors, children and stylesheet sources. Chrome yields [188,304,896,0], thus 304|1084. Before this change Mimic yields [16,280,928,18.390625].

The causes were general operations: the regex stylesheet reader flattened @media ancestry and applied the mobile 16px padding at a 1272px viewport; auto horizontal margins were not distributed; a normal paragraph did not wrap; and an input[type=hidden] contributed an anonymous line box. NOSCRIPT content also participated despite the scripting-enabled document. These are not a server-selected program difference.

The immutable rule program now traverses the existing parsed CSS AST, preserving media/supports guards. A private media evaluator shares canonical viewport and preference observations with MediaQueryList and styleMedia, including chained width/height ranges, conjunction/disjunction/negation, orientation and the existing preferences. It re-evaluates state per read, including a resized iframe, and never calls author-modified matchMedia or CSS.supports. The normal-flow model distributes horizontal auto margins and wraps text at whitespace using font-resource advances; hidden controls/NOSCRIPT do not create line boxes. Adjacent margins also collapse through empty blocks, retaining their original positions.

The original wrapper replay after the change yields exactly [188,304,896,0]. Raw private evidence is .build/residual-dom-delegated/wrapper-{native,mimic,mimic-after} and the extracted observations/stylesheet. This diagnostic uses offline intercepted saved responses, and is not a timing or capability oracle. Generic frozen controls are css_wrapper_flow_oracle.js and its Chrome152 JSON receipt: nested media/supports, range logic, auto margins, wrapping, hidden controls, empty blocks, author replacements, and child viewport changes all match independent headful A/B captures.

The API wrapper top/right cause is closed; this increment does not claim full flex sizing, arbitrary media/device features, fragmentation, hyphenation or complete inline formatting. The larger ancestor/footer heights still require flex and inline-content modeling if independently observed by a workload. No target coordinates, identifiers, text or hashes enter the implementation.

Follow-up: line wrapping shapes each candidate line before its single layout-unit rounding. Adding separately rounded word advances could exceed the exact max-content width and create a spurious second line in an absolutely positioned shrink-to-fit box. Eighteen independent Arial/Times New Roman controls cover different sizes and word sequences; both frozen runs and Mimic agree.
